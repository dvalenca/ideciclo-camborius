# Descrições Contextuais das Vias

## Como usar este arquivo
Adicione descrições específicas para cada via avaliada, incluindo contexto urbano, importância na rede cicloviária e características especiais.

## Template para Nova Via
```markdown
### [Nome da Via]
**Cidade**: [Camboriú/Balneário Camboriú]
**Tipologia**: [Ciclovia/Ciclofaixa/Compartilhada]

**Contexto urbano**: 
[Descrição da localização, bairros que conecta, pontos de interesse próximos]

**Importância na rede**: 
[Papel desta via na conectividade cicloviária da cidade]

**Características especiais**: 
[Aspectos únicos desta via, desafios específicos, etc.]
```

## Vias Cadastradas

### [Exemplo - Avenida Brasil]
**Cidade**: Balneário Camboriú
**Tipologia**: Ciclofaixa

**Contexto urbano**: 
Principal via de acesso à orla, conectando o centro da cidade às praias centrais.

**Importância na rede**: 
Via estruturante para o deslocamento cicloviário turístico e cotidiano.

**Características especiais**: 
Alto fluxo de pedestres e veículos, especialmente durante a temporada turística.
