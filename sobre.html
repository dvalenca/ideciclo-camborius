🚴 IDECICLO - Auditoria Cicloviária

O IDECICLO é uma iniciativa que visa avaliar e melhorar a infraestrutura cicloviária através de metodologia científica e coleta de dados em campo.

📊 Sobre este Relatório

Este relatório apresenta os resultados da auditoria cicloviária realizada em Camboriú e Balneário Camboriú, utilizando a ferramenta de auditoria cicloviária do IDECICLO.

👥 Equipe do Projeto

🚴

Equipe de Campo

Responsável pela coleta de dados in loco, utilizando a ferramenta de auditoria cicloviária para avaliar cada estrutura.

💻

Equipe de Desenvolvimento

Desenvolvimento do sistema de processamento de dados, dashboard e interface web para visualização dos resultados.

📊

Equipe de Análise

Análise dos dados coletados, desenvolvimento de métricas e sistema de avaliação das estruturas cicloviárias.
