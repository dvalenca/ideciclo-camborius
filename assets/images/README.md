# Galeria de Imagens

## Padrão de nomenclatura:
`[nome-gpx]-[1-4].[jpg|jpeg|png]`

## Exemplos:
- `Ciclofaixa Av. Atlântica - BC-1.jpg`
- `Ciclofaixa Av. Atlântica - BC-2.jpg`
- `Ciclofaixa Av. Brasil T1 - BC-1.png`

## Como adicionar imagens:
1. Salve as fotos nesta pasta
2. Use o nome exato do GPX (sem "EDIT GPX - " e ".gpx")
3. Numere de 1 a 4
4. Formatos aceitos: jpg, jpeg, png

## Funcionamento:
- O sistema tenta carregar automaticamente até 4 imagens por estrutura
- Se não encontrar imagens, mostra placeholder
- Clique na imagem para abrir em tamanho maior
